# Want to read

The queue: books I want to get to, newest addition first. This file is the
whole database — the build renders it at
[/reading/want-to-read.html](https://aaronstacy.com/reading/want-to-read.html),
and that page links straight back here for adding one from a phone.

Each bullet is one book:

    - Title — Author — an optional note

Author and note are optional, and `--` works in place of the em dash if it is
easier to type. Anything that is not a bullet — this preamble included — is
ignored by the build, so notes to self are fine anywhere in the file.

Once a book is started, drop its line from here and add `books/<slug>.md`
instead (see the README).
